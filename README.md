# Enhanced Lung Cancer Detection Using CNN with Hybrid SFO–SBS Optimization

This repository organizes the **Notebook 146** implementation of Paper 1. It is a binary **pulmonary nodule vs. non-nodule** image-classification workflow using handcrafted image features, SFO–SBS feature selection, and a fixed CNN classifier.

> **Scope:** Notebook 146 is the reference implementation. Notebook 147 and Paper 2 (HHO-CBAMNet) are not part of this repository.

## Workflow
1. Read the cleaned `train`, `valid`, and `test` image folders.
2. Resize grayscale images to 128 × 128 and extract the notebook's feature vector.
3. Fit StandardScaler on training features only; transform validation and test.
4. Select exactly 50 of 300 columns using binary SFO–SBS. Fitness is Logistic Regression validation ROC-AUC.
5. Reshape selected features to 10 × 5 × 1.
6. Train the fixed CNN; use validation AUC for checkpointing and early stopping.
7. Evaluate on the held-out test set.

Labels: `0 = non_nodule`, `1 = nodule`.

## Important feature-extraction caveat
Notebook 146 concatenates HOG, GLCM, statistical, and gradient features, then truncates to the first 300 values. With 128 × 128 images, 9 HOG orientations, 16 × 16 pixels/cell, and 2 × 2 cells/block, the HOG descriptor alone exceeds 300 values. Consequently, the retained 300 columns are HOG-only; the later GLCM/statistical/gradient values do not enter the final matrix. This repository preserves that reference behavior rather than silently changing the experiment.

Do not reuse the saved 50 indices after changing feature extraction. Regenerate the feature matrices and rerun feature selection as a separately documented experiment.

## Modular scripts
The scripts operate on the `.npy` feature matrices generated by the reference notebook:
```bash
python scripts/prepare_features.py --features-dir /path/to/paper1_features --output-dir results/scaled_features
python scripts/run_feature_selection.py --features-dir results/scaled_features --output-dir results/feature_selection
python scripts/train_cnn.py --features-dir results/scaled_features --indices results/feature_selection/selected_indices.npy --output-dir results/cnn
```
The input feature folder must contain `X_train_300.npy`, `X_val_300.npy`, `X_test_300.npy`, and `y_train.npy`, `y_val.npy`, `y_test.npy`. Feature extraction remains documented in `src/paper1/features.py`; use Notebook 146 as the reference execution record.

## Optimization scope
Notebook 146 optimizes the **feature mask only** (50 selected columns) with Logistic Regression validation AUC. CNN settings are fixed: filters 32/64/128, dropout 0.50, Adam learning rate 0.001, binary cross-entropy, batch size 32, up to 30 epochs. It does **not** perform CNN hyperparameter optimization.

See `docs/REPRODUCIBILITY.md` for settings and caveats.
